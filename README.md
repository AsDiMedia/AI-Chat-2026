# Local AI

One of the central ideas behind AI Chat 2026 is that AI does not automatically have to mean cloud AI.

Local models can run directly on your own hardware.

Depending on model size and hardware configuration, this can provide:

- Local processing
- Greater control over data
- Independence from API limits
- Predictable operating costs
- Offline-capable workflows
- Freedom to choose different models for different tasks

AI Chat 2026 supports workflows in which local models are used as the primary AI backend while external providers remain available when required.

---

# Central Local AI Server

Local AI does not necessarily mean that every workstation needs an expensive GPU.

A powerful system can host larger local models while multiple client computers use that system as an AI backend.

This makes architectures possible such as:

```text
Developer PC
     │
Developer PC
     │
Developer PC
     │
     ▼
Local AI Server
     │
Large Local Model
```

This approach can be useful for teams that want centrally controlled local AI without equipping every workstation with high-end GPU hardware.

# Supported AI Providers

# Hardware

The hardware required for local AI depends heavily on:

- Model size
- Quantization
- Context size
- CPU
- System memory
- GPU
- VRAM
- Desired generation speed

Small and medium-sized models can run on ordinary modern systems.

Larger models benefit significantly from dedicated GPU hardware and sufficient VRAM.

AI Chat 2026 does not lock users to one GPU vendor or one specific hardware configuration.

See:

`HARDWARE.md`

for additional guidance.

---

# Models

Different models are useful for different tasks.

For example:

- Coding models can be useful for software development.
- Reasoning models can be useful for analysis and complex planning.
- Smaller models can offer significantly faster responses.
- Larger models may provide better reasoning or code quality but require more hardware resources.

Model availability, hardware requirements and capabilities change rapidly.

AI Chat 2026 therefore focuses on model flexibility instead of permanently coupling the application to one specific model.

See:

`MODELS.md`

for more information.
