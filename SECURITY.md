# Security Policy

Security is important to the AI Chat 2026 project.

If you discover a potential security vulnerability, please do not publish detailed exploit information in a public GitHub issue.

Instead, contact:

support@chatai2026.com

Please include:

- AI Chat 2026 version
- Operating system
- Description of the issue
- Steps required to reproduce it
- Relevant logs or screenshots
- Potential security impact

Do not include passwords, API keys, access tokens, licence credentials or other sensitive information.

We will review security reports and investigate reproducible issues.

Official product information:

https://chatai2026.com/
